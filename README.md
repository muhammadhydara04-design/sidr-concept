# Sidr — bilingual EN/AR landing page concept

One page, two languages, two layouts. Toggle **EN ⇄ ع** in the top-right corner and the
whole page flips: native Arabic copy (not machine translation), right-to-left layout,
Arabic-Indic numerals, Arabic typography instead of a Latin font with Arabic glyphs bolted on.

Built as a concept piece to show what a bilingual page delivery looks like: the English
page that already sells, handed back as a working Arabic page.

**Not client work.** The brand, products, prices and testimonial are fictional. The banner
at the top of the page says so, on purpose.

- Single self-contained HTML file, no build step, no dependencies except two Google fonts.
- Responsive down to 360px.
- Language choice persists in `localStorage`.
